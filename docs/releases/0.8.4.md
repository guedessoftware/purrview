# PurrView 0.8.4

Esta versão corrige a inicialização visual do PurrView na baseline Qt 6.4 usada pelo Ubuntu 24.04.

## Correções

- Viewer e Composer são carregados por URL com suas propriedades iniciais, evitando a restrição de
  contexto dos componentes QML `Bound` no Qt 6.4.
- Os diálogos do shell e da lixeira usam dimensões explícitas, sem ciclos de `implicitWidth`.
- O comportamento foi reproduzido em Ubuntu 24.04 com Qt 6.4.2 usando renderização por software.

## Distribuição

- As instruções do Flatpak configuram o Flathub e distinguem instalação de bundle e compilação.
- O runtime KDE do Flatpak foi atualizado do ramo descontinuado 6.8 para o ramo estável 6.10.
