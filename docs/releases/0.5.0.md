# Impage 0.5.0

O Impage 0.5.0 é a primeira versão formal do projeto. Esta baseline reúne o visualizador de
imagens, o compositor de páginas A4 e a integração Linux construída nas fases anteriores.

## Principais novidades

- Viewer moderno com filmstrip, tela cheia, zoom, rotação e painel de informações.
- Composer com múltiplas páginas, grade, margens, espaçamento e impressão.
- Fluxo contínuo entre Viewer e Composer sem perder seleção ou configuração da composição.
- Abertura por linha de comando, gerenciador de arquivos, clipboard e arrastar e soltar.
- Distribuição preparada por source build, bootstrap nativo e Flatpak.

## Melhorias

- Caches de miniaturas e metadados possuem limites explícitos.
- Ações de arquivo usam APIs portáveis do Qt e a remoção nunca faz fallback para exclusão direta.
- Builds Debug e Release possuem testes automatizados e lint QML.

## Correções relevantes

- Registro do componente de preview corrigido para builds Release limpos.
- Metadados avançados degradam para informações básicas quando Exiv2 não está disponível.
- Consulta de ajuda e versão não exige mais uma sessão gráfica.

## Limitações conhecidas

- O manifesto Flatpak está preparado, mas impressão em impressora física dentro do sandbox ainda
  precisa de validação antes da publicação no Flathub.
- O bootstrap nativo é suportado oficialmente apenas em `x86_64`; `aarch64` ainda não foi testado.
- Ubuntu 24.04 fornece Qt 6.4 e não atende ao mínimo Qt 6.5 sem runtime privado; a baseline nativa
  mira Ubuntu 26.04 LTS ou mais recente.
- Abrir a localização e enviar arquivos à lixeira pode depender das permissões concedidas ao
  Flatpak.

Não há migração de configurações necessária nesta versão.
