# Impage 0.5.4

Esta versão amplia os formatos aceitos e torna instalação e atualização mais rápidas.

## Novos formatos

- AVIF (`.avif` e `.avifs`);
- HEIF/HEIC (`.heif`, `.heic` e `.hif`);
- Apple Icon Image (`.icns`).

Os formatos participam da abertura direta, descoberta da pasta, miniaturas, Viewer, Composer,
impressão, associações MIME e ação do Dolphin. O bootstrap instala KDE Image Formats e os codecs
AVIF/HEIF necessários. A disponibilidade continua sendo confirmada em runtime pelo Qt antes de um
arquivo ser aceito.

Para registrar o Impage como padrão apenas nesses formatos, sem usar a seleção global do KDE:

```bash
scripts/install-impage.sh --upgrade --set-default-viewer
```

## Bootstrap mais rápido

O bootstrap comum não compila os executáveis de teste na máquina do usuário. O release continua
sendo submetido à suíte completa antes de empacotar, e o binário instalado ainda é validado antes da
ativação. Para repetir toda a suíte localmente:

```bash
scripts/install-impage.sh --upgrade --verify
```
