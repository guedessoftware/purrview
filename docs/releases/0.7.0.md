# PurrView 0.7.0

Esta versão leva a identidade visual PurrView ao modo de visualização de imagens.

O Viewer agora tem cabeçalho com logotipo e ação de impressão destacada, barra de ferramentas em
vidro translúcido sobre a fotografia, navegação e seleção nas cores da marca, película de miniaturas
com contador de posição e painel de informações reorganizado. Em tela cheia, o cabeçalho desaparece
para ampliar a área útil sem perder os controles flutuantes.

## Atualização

```bash
scripts/install-impage.sh --upgrade
```

Após atualizar, feche janelas antigas do PurrView e abra o aplicativo novamente pelo menu.
