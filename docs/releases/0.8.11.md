# PurrView 0.8.11

Esta versão torna a barra do Composer mais compacta quando existem imagens selecionadas, mantendo
intactos o logotipo oficial e o nome visual do aplicativo.

## Interface

- O botão principal passa a exibir somente **Adicionar**.
- Limpar torna-se uma ação quadrada, identificada por ícone, dica de uso e nome acessível.
- As miniaturas aumentam de 46 para 51 px, aproximadamente 10%.
- Duplicar aparece no canto superior esquerdo da miniatura.
- Remover aparece no canto superior direito da miniatura.
- Os controles contextuais são exibidos na seleção ou ao passar o ponteiro e operam sobre toda a
  seleção quando várias imagens estiverem marcadas.
- Os atalhos `Ctrl+D` e `Delete`, além das ações do menu Imagens, continuam disponíveis.

## Validação

- Interface inspecionada com quatro imagens reais.
- Compilação Release concluída sem erros QML.
- Todos os testes automatizados aprovados.
