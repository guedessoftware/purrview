# Impage 0.5.3

Esta versão refina a integração visual do Viewer com o desktop e devolve o máximo possível de área
útil à imagem.

## Melhorias

- A janela declara explicitamente os controles nativos de minimizar, maximizar e fechar, além do
  menu do sistema, para o gerenciador de janelas.
- O título interno `Impage Viewer · arquivo` foi removido; o título nativo continua identificando o
  arquivo aberto para o sistema e para tecnologias assistivas.
- A toolbar superior passa a sobrepor a imagem, sem reservar uma faixa vazia no canvas.
- Em repouso, a toolbar fica bastante transparente; ao receber o ponteiro, ganha opacidade de forma
  animada.
- Um botão de alfinete mantém a toolbar no estado de maior opacidade, inclusive quando os demais
  controles entram em auto-hide na tela cheia.

## Integração com o painel do desktop

O Impage fornece uma janela nativa normal, com título, menu do sistema e todos os controles padrão.
KDE, GNOME e extensões de painel decidem se esses controles permanecem na decoração da janela ou
são movidos para o painel superior. O aplicativo não substitui a decoração por uma imitação própria,
preservando redimensionamento, maximização e compatibilidade com Wayland.
