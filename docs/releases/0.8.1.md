# PurrView 0.8.1

O PurrView agora apresenta sua identidade e informações técnicas em um diálogo **Sobre** próprio.
Ele mostra a versão obtida automaticamente do build, logotipo, descrição, licença, sistema,
arquitetura e a versão real do Qt em execução.

O diálogo pode ser aberto pelo menu **Ajuda > Sobre o PurrView** no Composer ou pelo menu de opções
da barra flutuante do Viewer. O botão do GitHub abre o endereço definitivo do projeto:
`https://github.com/guedessoftware/purrview`.

Todos os metadados de distribuição, pacotes e links de changelog também foram atualizados para o
novo endereço do repositório.
