# PurrView 0.8.3

Esta versão altera a licença do PurrView para a GNU General Public License versão 3
(`GPL-3.0-only`) em todo o código-fonte, interface, metadados e formatos de pacote.

Os dados pessoais de autoria e contato foram removidos da interface e dos arquivos públicos. O
repositório passa a identificar coletivamente a manutenção como **PurrView contributors** e mantém
somente os endereços públicos do projeto no GitHub.

Testes, workflows de integração contínua e scripts de geração de pacotes fazem parte do código
publicado para que qualquer pessoa possa verificar e reproduzir os builds. Diretórios de build,
caches, logs e pacotes gerados permanecem excluídos pelo `.gitignore`.
