# PurrView 0.8.13

Esta versão consolida PurrView como identidade técnica do projeto e prepara o aplicativo para o
ciclo de estabilização 0.9.x.

## Identidade e compatibilidade

- `purrview` passa a ser o executável real e principal.
- `impage` permanece temporariamente como wrapper compatível.
- AppStream, desktop files, Flatpak e integrações usam
  `io.github.guedessoftware.PurrView`.
- Instalações bootstrap e preferências do nome histórico possuem migração assistida.

## Distribuição

- Metadados e documentação foram sincronizados para DEB, RPM, Arch e Flatpak.
- Foram adicionadas orientações para futura submissão ao Flathub e ao AUR.
- O fluxo de release pode gerar opcionalmente uma assinatura GPG para `SHA256SUMS`.
- Source e bootstrap tarballs continuam reproduzíveis e o build normal permanece offline.

## Compatibilidade visual e de sistema

- Tema claro, tema escuro e acompanhamento do tema do sistema foram preservados.
- Os controles usam ícones vetoriais internos em vez de glifos dependentes da fonte.
- Permanecem os fallbacks para Qt 6.4+ e SELinux enforcing.
