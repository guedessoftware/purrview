# PurrView 0.8.0

Esta versão transforma o processo de distribuição em uma matriz reproduzível. Um único comando
produz os arquivos universais source e bootstrap, além de pacotes DEB, RPM, Arch e Flatpak.

Cada pacote binário é compilado em um ambiente isolado correspondente ao destino, executa os dez
testes automatizados, é instalado no próprio container e tem binário, versão, lançadores e
metadados AppStream verificados antes de chegar a `dist/0.8.0/`.

As bases estáveis são Ubuntu 24.04 para DEB e AlmaLinux 9 para RPM. O pacote Arch usa a distribuição
rolling atual, e o Flatpak usa o SDK KDE 6.8 oficial, com Exiv2 0.28.8 e `inih` incorporados somente
ao sandbox. O mínimo Qt do código-fonte passa a ser 6.4.

## Gerar todos os pacotes

```bash
scripts/package-all.sh
```

Consulte `docs/packaging.md` para compatibilidade, opções seletivas e limites de validação.
