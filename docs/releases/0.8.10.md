# PurrView 0.8.10

Esta versão dá acabamento à barra de ações do Composer e diferencia os dois atalhos instalados no
menu de aplicativos.

## Interface

- Botões com 42 px de altura, padding horizontal uniforme e conteúdo centralizado.
- Estados neutros de repouso, foco, hover e pressionado coerentes nos temas claro e escuro.
- Hierarquia preservada: adicionar imagens recebe destaque suave e imprimir mantém o gradiente da
  marca.
- Ações exibidas durante a seleção também usam o mesmo componente e a duplicação ganha ícone
  vetorial próprio.

## Integração com o sistema

- O compositor é identificado como **PurrView Print**.
- Em ambientes configurados para português do Brasil, o nome localizado é **PurrView Impressão**.
- O visualizador permanece identificado como **PurrView**, evitando dois atalhos com o mesmo nome e
  o mesmo ícone.

## Validação

- Compilação Release concluída.
- Arquivos desktop validados com `desktop-file-validate`.
- Todos os 11 testes automatizados aprovados.
