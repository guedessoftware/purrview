# PurrView 0.8.2

Esta atualização finaliza o acabamento visual do diálogo **Sobre o PurrView**. O conteúdo agora
fica em uma superfície opaca e uniforme, com cabeçalho próprio, um único controle de fechamento e
hierarquia mais clara entre identidade, versão e informações técnicas.

O botão **Abrir projeto no GitHub** ganhou tamanho, contraste e estados de interação consistentes
com a identidade visual do aplicativo. O endereço de contato também apresenta resposta visual ao
mouse e abre diretamente o cliente de e-mail padrão.
