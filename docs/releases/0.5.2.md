# Impage 0.5.2

Esta correção restaura a abertura direta de imagens e as ações do Impage no Dolphin quando a sessão
gráfica não inclui `~/.local/bin` no `PATH`.

## Correções

- Os lançadores **Impage** e **Impage Viewer** passam a apontar para o executável absoluto instalado
  pelo bootstrap.
- A ação **Montar no Impage** do menu de contexto do Dolphin usa o mesmo caminho confiável.
- O bootstrap valida os três lançadores antes de ativar a instalação.
- Ao concluir, o instalador mostra o caminho correto para iniciar o Impage pelo terminal.
- A documentação explica onde encontrar o executável instalado e por que `build/release` não existe
  no pacote bootstrap.

## Atualização

Extraia `Impage-0.5.2-bootstrap.tar.xz` e, como usuário normal do desktop, execute:

```bash
scripts/install-impage.sh --check
scripts/install-impage.sh --upgrade
```

Após a atualização, o aplicativo pode ser iniciado pelo menu, ao abrir uma imagem no Dolphin, pelo
menu de contexto ou diretamente com `~/.local/bin/impage`.
