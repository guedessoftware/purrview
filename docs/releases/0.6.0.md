# PurrView 0.6.0

Esta versão apresenta a nova identidade do aplicativo. O projeto antes exibido como **Impage**
passa a se chamar **PurrView**, com o logotipo vetorial do gatinho fornecido pelo projeto.

## Interface

- Cabeçalho com marca PurrView, ações principais maiores e impressão em gradiente.
- Painel de configuração agrupado em cartão, com cores que identificam cada seção.
- Área de composição mais limpa e barra inferior com papel, orientação, grade e zoom de 50% a 150%.
- Ícone nativo da janela e do menu de aplicativos baseado no novo logotipo.

## Compatibilidade

O identificador de desktop e a pasta de instalação interna foram preservados para que a atualização
substitua a versão anterior sem perder associações. O comando recomendado agora é `purrview`; o
comando `impage` continua funcionando para scripts e atalhos existentes.

## Atualização

Extraia `PurrView-0.6.0-bootstrap.tar.xz` e execute, como usuário normal:

```bash
scripts/install-impage.sh --upgrade
```
