# PurrView 0.6.1

Esta correção garante que o logotipo do PurrView apareça no menu de aplicativos e na barra de
tarefas do KDE Plasma.

O pacote instala o ícone como PNG em todos os tamanhos comuns do tema Hicolor, configura os
lançadores com o caminho absoluto da versão de 256 px e publica o mesmo PNG como ícone nativo da
janela. O instalador também força a atualização do cache de ícones após o upgrade.

## Atualização

```bash
scripts/install-impage.sh --upgrade
```

Após atualizar, feche qualquer janela antiga do PurrView e abra o aplicativo novamente pelo menu.
