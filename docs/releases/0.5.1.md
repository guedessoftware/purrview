# Impage 0.5.1

Esta correção torna a instalação nativa confiável em sistemas configurados para português e evita
que o modo por usuário seja instalado acidentalmente no diretório pessoal de `root`.

## Correções

- O teste de metadados aceita corretamente separadores decimais localizados, como `f/5,6` em
  português brasileiro.
- `scripts/install-impage.sh --user` agora recusa `/root` e explica como executar pelo usuário do
  desktop.
- O modo `--check` executado como root apenas avisa sobre o usuário incorreto e continua o
  diagnóstico sem alterar o sistema.

## Instalação

Extraia o novo arquivo `Impage-0.5.1-bootstrap.tar.xz`, abra um terminal como usuário normal e
execute:

```bash
scripts/install-impage.sh --check
scripts/install-impage.sh --user
```

Não use `sudo` no segundo comando. Se uma dependência estiver ausente, o próprio instalador pedirá
autorização apenas para executar o gerenciador de pacotes.

As limitações de Flatpak e arquitetura permanecem iguais às documentadas para a versão 0.5.0.
