# PurrView 0.7.1

Esta atualização refina a experiência imersiva do Viewer.

O cabeçalho interno adicional foi removido, e o logotipo, o nome PurrView e a ação **Imprimir** agora
integram a própria barra flutuante de ferramentas. A imagem volta a aproveitar toda a janela.

A película de miniaturas passa a sobrepor a fotografia com transparência leve. Ao encerrar a
navegação, ela desliza suavemente para baixo após 2,3 segundos; aproximar o ponteiro da borda
inferior torna a película visível novamente. O contador textual de posição também foi removido.

## Atualização

```bash
scripts/install-impage.sh --upgrade
```
