# PurrView 0.8.7

Esta versão permite que a interface acompanhe a aparência clara ou escura escolhida no sistema.

## Aparência

- O tema escuro existente foi preservado com exatamente as mesmas cores.
- Uma paleta clara própria mantém contraste, legibilidade e os destaques coloridos do PurrView.
- Composer, Viewer, menus, controles, painéis, faixa de miniaturas e diálogo Sobre compartilham o
  mesmo esquema de cores.
- Em Qt 6.5 ou superior, alterações do tema do sistema são aplicadas enquanto o aplicativo está
  aberto.
- No Qt 6.4, a aparência é detectada pela paleta do desktop durante a inicialização.

## Validação

- Testes automatizados cobrem as paletas clara e escura e a detecção por contraste.
- A interface QML é validada para evitar cores ou propriedades incompatíveis.
